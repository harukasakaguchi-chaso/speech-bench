Web Speech API（日本語）を、同じ原稿でブラウザごとに測るツールです。誤字脱字・句読点・フィラー・速度・連続認識の安定性を記録します。

正解テキストは、読み上げる文から［］の部分を除いて自動で作ります。句読点の位置も正解として扱います。

Chrome 139 以降の端末内認識（ja-JP）の状態を確認します。
測り方のコツ
  1. 原稿 A・B・C の 3 本を、同じマイク・同じ部屋で、各ブラウザ 3 回ずつ読むと差が見えやすくなります（1 ブラウザあたり約 5 分）。
  2. 読む人の揺れをなくすなら、同じ録音を別の端末から再生してマイクに聞かせるか、仮想オーディオ（BlackHole など）を入力にします。
  3. 読み終えたら 2 秒ほど待ってから「停止」を押してください。停止後に確定する分も計測します。
  4. 他のブラウザの結果は「書き出し（JSON）」で保存し、ここで「読み込み」すると 1 つの表で比べられます。

音声は各社のサーバー（Google・Microsoft・Apple）に送られます。個人情報や社外秘の内容は読み上げないでください。
